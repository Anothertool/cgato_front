# CGato frontend

Base en JavaScript con React, Vite y Chakra UI.

## Desarrollo

Con una versión de Node.js compatible con Vite:

```sh
npm install
npm run dev
```

## Compilación

```sh
npm run build
npm run preview
```

La aplicación empieza en `src/main.jsx`, donde se configura Chakra UI.
El componente inicial está en `src/App.jsx`.

En PowerShell, si la política de scripts bloquea `npm`, utiliza `npm.cmd`.
